Script Loader Generator

Raw URLを貼ると loadstring ローダーを自動生成します

対応する自動変換:
• GitHub github.com/user/repo/blob/... → raw.githubusercontent.com
• GitHub Gist gist.github.com/... → gist.githubusercontent.com/.../raw
• Pastebin pastebin.com/XXXX → pastebin.com/raw/XXXX
• Pastebin pastebin.com/raw/XXXX はそのまま

注意: 他人のスクリプトを無断で読み込ませる行為は規約違反・著作権侵害になる場合があります。自分が作成した、または利用許諾のあるスクリプトにのみ使用してください。
